# 智能商品导购后端系统

基于 FastAPI + MySQL 实现的智能导购后端服务，手写 RAG 检索增强生成逻辑，支持多轮对话条件继承，遵循后端工程化开发规范。

## 技术栈
- 后端框架：FastAPI + Uvicorn
- 数据库：MySQL 8.0 + PyMySQL
- AI 能力：大模型 API + 手写 RAG 检索增强生成
- 工程化：路由分层、统一返回格式、全局异常处理、日志系统、配置分离

## 核心功能
1.  **商品管理**：商品增删改查、分类管理、多条件分页查询
2.  **智能导购**：基于商品库的多轮对话问答，自动解析用户预算、品类筛选条件
3.  **会话持久化**：历史筛选条件自动保存，支持多轮上下文继承
4.  **工程化规范**：全局异常兜底、操作日志留痕、敏感配置环境变量管理
