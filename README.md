# 智能商品导购后端系统

基于 FastAPI + MySQL 实现的智能导购后端服务，手写 RAG 检索增强生成逻辑，支持多轮对话条件继承，遵循后端工程化开发规范。

## 技术栈
- 后端框架：FastAPI + Uvicorn
- 数据库：MySQL 8.0 + PyMySQL
- AI 能力：大模型 API + 手写 RAG 检索增强生成
- 工程化：路由分层、统一返回格式、全局异常处理、日志系统、配置分离

## 核心功能
1.  **商品管理**：商品增删改查、分类管理、多条件分页查询
2.  **智能导购**：基于商品库的多轮对话问答，自动解析用户预算、品类筛选条件
3.  **会话持久化**：历史筛选条件自动保存，支持多轮上下文继承
4.  **工程化规范**：全局异常兜底、操作日志留痕、敏感配置环境变量管理

## 项目亮点
1.  **原生手写结构化RAG方案**：通过大模型提取用户筛选条件，结合数据库精准检索商品后生成回复，有效解决大模型商品信息幻觉问题，提升回答准确率。
2.  **全链路工程化规范**：按业务领域拆分路由模块，封装统一返回格式与错误码体系，实现双层全局异常捕获与分级日志系统，提升代码可维护性与问题排查效率。
3.  **多轮会话持久化**：自动继承历史筛选条件，支持连贯导购对话，会话数据落地MySQL存储，支持回溯查询。
4.  **生产级数据库适配**：完成从SQLite到MySQL的平滑升级，设计商品、分类、会话三张核心表，添加索引优化多条件查询性能。


## 本地启动
1.  克隆项目并进入根目录
2.  安装依赖：`pip install -r requirements.txt`
3.  在根目录创建 `.env` 文件，配置大模型密钥与 MySQL 连接信息
4.  启动服务：`uvicorn main:app --reload`
5.  接口文档：访问 `http://127.0.0.1:8000/docs` 在线调试
